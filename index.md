## Projects

- **[vit-thesis](https://github.com/GiorgosPapado/vit-thesis)**: code for my MSc thesis, Vision Transformers vs. PCA+SVM for EMG gesture recognition. The repository does not reproduce the thesis numbers and has no verified re-run results yet.
- **[vr-gesture-recognition](https://github.com/GiorgosPapado/vr-gesture-recognition)**: train VR controller gesture models in Python, export to ONNX, run in Unity or WebXR; plus tooling and weak baselines for a cleaned hand-gesture set (data not included).
- **[Tower-Defence](https://github.com/GiorgosPapado/Tower-Defence)**: a Unity 3D tower defence game with 8 waves and 3 turret types, plus a small builder AI trained with evolution strategies that doubles as a balance tester.
- **efficient-inference**: ONNX Runtime benchmarks and an in-progress Once-for-All-style elastic transformer for EMG; results so far are sanity-level. TODO(author): add the link once the repository is public.
